# Zero Dot Force

The labs incubator for [Unbound Force](https://github.com/unbound-force).
The tools here check the quality of AI-written code and tests.

## Projects

| Project | What it does | Get it |
|---------|--------------|--------|
| [vibe-check](https://github.com/zero-dot-force/vibe-check) | Coupling, cohesion and dependency-cycle metrics for Go, Python and TypeScript, emitted as JSON. | [Releases](https://github.com/zero-dot-force/vibe-check/releases) |
| [reading-stone](https://github.com/zero-dot-force/reading-stone) | TypeScript analyzer for [Gaze](https://github.com/unbound-force/gaze): side effects, coverage and test-to-assertion mapping. | [npm](https://www.npmjs.com/package/reading-stone) |
| [snake-eyes](https://github.com/zero-dot-force/snake-eyes) | Python analyzer for [Gaze](https://github.com/unbound-force/gaze): side effects, coverage and test-to-assertion mapping. | [PyPI](https://pypi.org/project/snake-eyes-analyzer/) |
| [review-council](https://github.com/zero-dot-force/review-council) | Six specialist AI reviewers (security, architecture, testing and more) that review a change in parallel and return one verdict. | [Lola module](https://github.com/zero-dot-force/review-council#readme) |

[Gaze](https://github.com/unbound-force/gaze) scores whether tests actually
verify behavior rather than just cover lines. reading-stone and snake-eyes
let it analyze TypeScript and Python.
